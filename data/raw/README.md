\# Data



The MIMIC-IV dataset is NOT included in this repository due to the 

PhysioNet Data Use Agreement.



\## How to get the data



1\. Go to https://physionet.org/content/mimiciv/

2\. Log in with your PhysioNet account

3\. Accept the Data Use Agreement if you haven't already

4\. Download the dataset files

5\. Place them in this folder before running the preprocessing script



\## Files expected here



\- hosp/admissions.csv.gz

\- hosp/patients.csv.gz

\- hosp/diagnoses\_icd.csv.gz

\- hosp/labevents.csv.gz

\- hosp/chartevents.csv.gz

\- icu/icustays.csv.gz

\- note/discharge.csv.gz
